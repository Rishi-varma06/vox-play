# Demo kit

Pre-generated, so nothing has to work live.

| File | What it is |
|---|---|
| `1_opera_game.html` | Morphy 1858, full pipeline with model-written commentary |
| `2_live_lichess_game.html` | A real blitz game pulled from Lichess |
| `show_gate.py` | The verification gate catching invented commentary, offline |

Open either HTML file in a browser and press play. One file each -- board,
audio and captions embedded, no server and nothing to install.

The runbook is `../docs/demo.md`.
